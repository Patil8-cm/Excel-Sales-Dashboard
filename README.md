# Excel-Sales-Dashboard

## Project Overview
This Excel Dashboard analyzes sales performance using Pivot Tables, Pivot Charts, Slicers, and KPIs.

## Features
- Interactive Dashboard
- Sales Analysis
- Region-wise Performance
- Monthly Sales Trends
- Top Products
- Dynamic Filters (Slicers)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Slicers
- Power Query (Optional)

## Key Insights
- Highest Sales Region
- Best Selling Product
- Monthly Revenue Trends
- Customer Analysis
